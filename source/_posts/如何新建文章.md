## 新建 Wiki 文章
操作：

1. 打开对应分类的配置文件，比如 source/_data/wiki/math1.yml
2. 在 tree 下面找到你要放文章的分类，加上一行：
```
- 新文章名字（拼音，小写，用连字符）
```
3. 在 source/wiki/math1/ 目录下创建同名 .md 文件
文件开头写三行：
```
wiki: math1
title: 显示的中文标题
---
```
4. 然后开始写正文


## 新建普通文章
操作：
1. 在博客根目录打开终端，执行：
```
hexo new post "文章标题"
```
2. 在 source/_posts/ 下找到生成的 .md 文件，编辑开头：
```
categories: 你想要的分类名
tags:
  - 标签1
  - 标签2
```

3. 在 --- 后面写正文


## 发布
写完后发布
```
hexo clean
hexo generate
git add .
git commit -m "新增文章"
git push
```
等 1-2 分钟，线上更新。
